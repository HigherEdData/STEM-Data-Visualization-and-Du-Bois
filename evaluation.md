Instructors can click here to
<a href="https://github.com/HigherEdData/STEM-Data-Visualization-and-Du-Bois/raw/refs/heads/main/episodes/files/stem-+-du-bois-assignments-and-surveys-export.imscc"
download>download this IMS common cartridge file</a>
that can be imported into Canvas or other learning management systems.
The IMS common cartridge file includes "quiz" assignments that can be assigned
as in class or at home assignments with questions for students to 
evaluate their understanding of the STEM + Du Bois module content.

The instructor can select from different versions of the quizzes that
correspond to the different R, Python, and Stata coding interactives
available on this lesson module site.

The quiz assignments include questions that ask students to upload an html file
output of their completed Jupyter Notebook coding interactives.
Instructions are included within with each coding interactive for
how students can save an html copy of their completed notebook that displays
their name on the graphs they recreate.

The html file uploads can then be viewed in speed grader
when reviewing quiz assignments submitted in Canvas. All questions
in the quiz assignments also have an answer key that displays
corresponding answers for instructors when they review students'
quiz question responses in Canvas.

For any questions about the Canvas assignments, email Principal Investigator
Charlie Eaton at ceaton2@ucmerced.edu.
