These coding interactives use Jupyter Notebooks that you can open and use with any web browser without any software installations on your own computer. This is ideal for beginners with R who do not yet want to learn how to use the R studio interface on their own computers.

If you plan to use R in the future, however, we recommend that you instead try the activities from our [Python STEM Data Visualization with Du Bois]() lesson site. That site has activities with Du Boisian examples for learning to use R studio for data visualization on your own computer.
